隐私政策

最后更新日期：2026年4月20日

感谢您选择 ZoomToolkit。我们非常重视您的隐私，本隐私政策旨在告知您我们如何处理（或不处理）您的信息。

1. 信息收集

ZoomToolkit 是一个纯客户端的浏览器扩展。我们不收集、不存储、也不传输您的任何个人数据或隐私信息。

  • 个人身份信息： 我们不收集您的姓名、电子邮件地址或任何联系方式。
  • 浏览历史： 我们不会跟踪或记录您的浏览活动。
  • 会议内容： 本插件仅修改 Zoom 网页版的显示样式，不会读取、记录或上传您的会议音频、视频或聊天记录。

2. 权限说明

为了使插件正常工作，我们需要以下权限：

  • activeTab： 仅用于在您当前打开的 Zoom 页面上运行增强脚本。
  • 访问 zoom.us 域名： 用于向 Zoom 会议页面注入 CSS 和 JS 以实现剧场模式等增强功能。

3. 第三方服务

ZoomToolkit 不包含任何第三方追踪代码或分析工具（如 Google Analytics）。所有逻辑均在您的浏览器本地运行。

4. 政策变更

如果我们将来对隐私政策进行任何更改，我们将在本页面发布更新版本。建议您定期查看。

5. 联系我们

如果您对本隐私政策或 ZoomToolkit 有任何疑问，请通过 GitHub Issue 或您的联系方式与我们联系。
